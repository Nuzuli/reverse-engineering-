# Panduan Berkontribusi (Contributing Guide) 🤝

Terima kasih telah berkontribusi di proyek **datafactor - Reverse Engineering**! Untuk menjaga kualitas analisis dan keamanan repositori, mohon ikuti panduan berikut.

## 🛡️ Etika & Batasan Keamanan
1. **Dilarang keras mengunggah Malware Aktif / Ransomware / Virus** ke repositori ini. Jika menganalisis sampel berbahaya, gunakan branch terpisah dan pastikan file telah di-archive dengan password (misal: menggunakan password `infected`) atau diubah ekstensi file-nya menjadi `.bin.mock`.
2. **Hapus Data Sensitif:** Pastikan tidak ada API Key, token, IP server privat, atau kredensial pribadi yang ikut terunggah dalam skrip atau dokumentasi.

## 📝 Format Dokumentasi Analisis
Setiap kali kakak menyelesaikan analisis sebuah biner/sistem, buat file `.md` baru di dalam folder `/docs` dengan format berikut:
* **Informasi File:** Hash (MD5/SHA256), Ukuran, Arsitektur (x86/x64/ARM), Packer yang digunakan (UPX, dll).
* **Tujuan Analisis:** Apa yang ingin dicari (misal: mencari algoritma enkripsi, memotong validasi lisensi).
* **Langkah Analisis:** Alur dari fungsi utama (`main` atau `Entry Point`) hingga target fungsi ditemukan.
* **Kesimpulan/Hasil:** Kode rekonstruksi (pseudo-code) atau ringkasan arsitekturnya.

## 🚀 Alur Git (Git Workflow)
1. **Fork atau Buat Branch Baru:** Jangan langsung commit ke branch `main`. Gunakan format nama branch:
   * `analysis/nama-target` (untuk dokumentasi riset/pembedahan)
   * `tool/nama-script` (untuk penambahan script otomatisasi)
2. **Kirim Pull Request (PR):** Tulis deskripsi singkat mengenai apa yang dianalisis atau script apa yang ditambahkan.
3. **Review:** Tunggu review dan persetujuan dari maintainer sebelum di-merge ke branch `main`.
